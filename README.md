# 🎓 Проект «ГМУ-магистратура 2027»

Подготовка двух студентов (выпускники направления **«Организация работы с молодежью», профиль «Государственная молодежная политика»**) к поступлению в **магистратуру на бюджет** по направлению **38.04.04 «Государственное и муниципальное управление»**.

**Вузы:** МГУ (факультет государственного управления) · РГСУ · РУДН

---

## 📌 Суть проекта

За 1 год (сентябрь 2026 → август 2027) освоить программу бакалавриата ГМУ **на базе учебного плана МГУ ФГУ** (самый сложный вуз из трёх — готовимся по нему, остальные закроются автоматически).

Вся программа разбита на **12 блоков** (примерно 1 блок = 1 месяц). Каждый блок делится на **недели**, каждая неделя устроена одинаково:

| День | Активность | Формат |
|------|-----------|--------|
| Пн–Вт | 📖 Лекция-конспект | читаем конспект темы (генерирую по запросу) |
| Ср | 🎬 Видеолекция | смотрим видео по теме |
| Чт–Пт | 🧩 Закрепление + кейс | разбираем практическую задачу |
| Сб | ✅ Тест самопроверки | ~10 вопросов, ответы сразу |
| Вс | ⏱ **Срезовый тест недели** | зачет: ≥70% = неделя сдана |

**Конец каждого блока (последние 2 дня месяца)** — большой срез: 40–60 вопросов + кейс-задача + разбор ошибок.

## 📖 Формат учебного дня

Каждый день = **один HTML-файл**. Открыл двойным кликом → всё внутри:
конспект с схемами и таблицами · интерактивные вопросы-спойлеры по ходу чтения · задание на вечер с чекбоксами · **встроенный тест дня** (мгновенная проверка, объяснение ошибок, зачёт от 70%).

Дашборд (`index.html`) показывает прогресс: дни, сданные на зачёт, отмечаются автоматически. Прогресс хранится в браузере — учиться лучше всегда с одного браузера (или синхронизироваться через профиль).

## 🤝 Как работать вдвоём (доступ для друга)

**Вариант 1 — GitHub (надёжно):**
1. Создаёшь **приватный репозиторий** на github.com, загружаешь эту папку.
2. Друг ставит **GitHub Desktop** (не нужен git в консоли: кнопки Pull/Push) и клонирует папку.
3. Правило: каждый ведёт свой раздел в `03_прогресс/трекер.md`, чтобы не конфликтовать.

**Вариант 2 — просто:** общая папка Google Drive / Яндекс.Диск, кидаешь другу ссылку. Минус — конфликты при одновременном редактировании.

⚠️ Прогресс тестов хранится локально в браузере каждого — у друга будет свой счётчик, это нормально.

## 🤖 Как использовать меня (AI-ассистент)

Контент генерируем **по запросу**, чтобы не держать гигантские объёмы заранее:

- Пишешь мне: *«Сделай день N»* или *«Сделай неделю N блока M»* → я создаю HTML-страницы дней: конспект + интерактивные вопросы + встроенный тест (как день 1).
- После срезов: *«Разбери мои ошибки по тесту»*.
- Перед олимпиадами: *«Устрой тренировочный вариант Универсиады»* / *«Прорешаем демовариант Я-профессионал»*.
- Любую тему отдельно: *«Объясни административные процедуры как для новичка»*.

⚠️ **Про видеоссылки:** я не выдумываю ссылки на YouTube (могу ошибиться адресом). В блоках указаны **точные поисковые запросы** и платформы ([Открытое образование](https://openedu.ru), YouTube, Рутуб, лектории вузов). Конкретную ссылку находи по запросу за 30 секунд или проси меня — найду и проверю в моменте.

## ✅ Правила успеха (читать вместе!)

1. **Не пропускать воскресные срезы** — они главный индикатор прогресса.
2. Провалил срез (<70%) → повтор темы на следующий день, ретейк во вторник.
3. Раз в месяц — совместный разбор блока по видеосвязи (1 час): объяснить тему друг другу = лучший способ выучить (метод Фейнмана).
4. Кейсы решаем письменно, потом сверяем — это тренировка финалов олимпиад и ДВИ.
5. Дедлайны олимпиад — священны, см. `00_поступление/олимпиады.md`.
